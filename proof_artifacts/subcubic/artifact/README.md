# Supplied A1 certificate files

The five JSON files and six Python modules are copied unchanged from the corresponding `artifact/` directory inside the frozen reproducibility archive. Their hashes appear in the repository's [SHA256SUMS.txt](../../../SHA256SUMS.txt).

Run the supported verification entry point from the repository root:

```sh
python -I -B proof_artifacts/subcubic/verify.py
```
