Reviewed on 28 October 2026:

The useful organisational features were an overview, a manuscript index, per-manuscript PDF/source/build/citation files, separately described proof artifacts, and a version history. This repository adapts those organisational ideas to its own single manuscript and problem family. Its catalogue prose and overview are written for the doubled-graph project; no OpenAI mathematical manuscript, logo, formalisation, compute claim or review status is reproduced as part of this deposit.

The author's existing CC BY 4.0 / MIT material-specific licence choices continue to apply. The full paper and original reproducibility archive preserve their initial-deposit bytes. Verification, authorship and novelty statements describe this project and are recorded separately in the linked documents.
